# Publications

Papers that use landau to compute phase diagrams. To add yours, open a pull request against this page.

- M. Poul, L. Huber, J. Neugebauer,
  *Automated generation of structure datasets for machine learning potentials and alloys*,
  npj Computational Materials **11**, 174 (2025).
  [doi:10.1038/s41524-025-01669-4](https://doi.org/10.1038/s41524-025-01669-4)

  Machine learning potentials for Mg–Al–Ca and the binary phase diagrams derived from them.

- S. Menon, M. Poul, T. Hickel, J. Neugebauer, R. Drautz,
  *Computing binary alloy phase diagrams with explicit configurational and vibrational entropy*,
  arXiv:2607.14795 (2026).
  [doi:10.48550/arXiv.2607.14795](https://doi.org/10.48550/arXiv.2607.14795),
  data and scripts: [doi:10.5281/zenodo.23780892](https://doi.org/10.5281/zenodo.23780892)

  Au–Cu phase diagrams from free energies with non-ideal configurational entropy sampled explicitly.
